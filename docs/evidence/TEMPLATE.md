Copy into the stage's evidence directory and replace every placeholder before claiming a verdict.

## Claims

| Criterion | Result | Reproduction and direct evidence | Limitations |
| --- | --- | --- | --- |
| Required ID | NOT DEMONSTRATED | Exact command or browser steps | Missing proof |

## Commands and observations

Record actual commands, working directory, exits, relevant outputs and safe artifacts. For browser evidence record routes, viewport, input actions, actual results and stable entity/revision IDs. For live effects include provider/tool receipts and domain results with sensitive values removed.

## Negative probes and findings

Include permission, stale revision, invalid input, failure/cancellation/restart and uncertainty probes relevant to the scope. Give each finding severity, user effect, owner, repair commit and recheck evidence. Preserve earlier failed attempts.

## Verdict and next action

State PASS / PASS WITH NON-BLOCKING FINDINGS / HELD / FAIL / BLOCKED, the exact scope and tested SHA, missing evidence, owner review status and next authorized work. A filled template alone is not proof.
