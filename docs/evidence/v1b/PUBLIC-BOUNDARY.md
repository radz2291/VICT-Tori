## Dependency decision

T07 requires public VICT discovery, canonical edit, observation and cancellation with a shared authoring contract. The existing public graph operations cover local mutation, and the existing public agent services cover turn governance. The missing seam is the **reusable, governed proposal/acknowledgement bridge** between the two. A plain Mastra tool can request an edit; it cannot safely turn a model or client supplied definition ID into permission or prove a concurrent browser edit applied once. A second TORI-specific authority path would depart from this slice's public VICT boundary.

Propose a separately authorized, narrow VICT dependency slice: expose the proposal, applied/rejected acknowledgement, observation and cancellation fence as a public host-neutral authoring interface. Bind it to trusted actor/target/revision and stable operation ID; retain outcome against the exact turn. Allow an adapter to supply the Flow graph source and journal commit so TORI can reuse its existing manual edits, explicit Save and activation. Verify a retry, stale revision, denied target and cancellation before publishing or changing the TORI pin. Keep Designer adoption and its paused work out of that slice. An alternative decision is to explicitly accept a TORI-hosted draft transaction adapter composed from the existing lower-level VICT exports as the T07 boundary. It would reuse VICT's activation and tool authority and Flow journal, while TORI would own the live draft binding and commit/acknowledgement transport. The owner decision is where that shared draft operation should live.

T07-01 through T07-07 remain **NOT DEMONSTRATED**. This mapping does not establish a live turn, an authoring receipt or separate consumer acceptance.
