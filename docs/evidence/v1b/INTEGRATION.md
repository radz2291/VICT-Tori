| Role | Implementation |
| --- | --- |
| Activation and capability authority | The operator adds Draft Authoring in Configure and explicitly saves and activates the profile. The VICT profile pins discovery and instruction editing at revision 1. The Mastra composition invokes the VICT grant gate with the local actor and the exact authorized turn. The host permits one scoped instruction edit through its exact quiet-write policy after the operator submits the turn for the current draft. |
| Draft binding | The loopback host authorizes an existing saved definition in its local workspace. The same browser tab binds a new open draft identity to the current saved revision and instruction occurrence. Model input carries only the proposed text and expected target and revision. The channel token stays between the local host and the editor tab. |
| Canonical edit | Public `createDraftAuthoring` dispatches the bound proposal. At the editor, public `commitDraftEdit` checks the fingerprint, target, revision and Stop fence. TORI maps the instruction occurrence to its existing VICT Flow parameter and uses the same `GraphSessionV3.apply` path as manual edits. A competing Save to that definition waits for the active turn. |
| Receipt and recovery | The editor stores the journal action and matching receipt in one browser session storage record before exposing the validated edit. It replays the Flow journal on same-tab reload and retains unacknowledged receipts until the host confirms them. The SQLite operation table verifies the channel and expected binding, stores each receipt once, and supplies the Run timeline. A late applied receipt can appear in a stopped Run. Save and Activate remain explicit. |
| Cancellation | Studio latches Stop at the browser journal before sending the cancellation request. The host propagates it through `AgentTurnService.cancelTurn`. A proposal received after the fence cannot apply. A prior commit retains its applied receipt and can be undone. |
| UI control inventory | The original dock audit applies to the shell, Assembly, Configure, Canvas, Sessions, Runs and the disabled Workflows and Creative buttons. The authoring activation uses VICT Select. Requested change uses VICT AI Textarea. Send, Stop and Inspect authoring Run use VICT Button. Availability, progress and outcome use VICT Feedback. Draft receipt details are read-only in Runs. [Original control audit](README.md#installed-control-roles) |

Open the exact authoring Run from the dock and use its Session link to see the corresponding turn. At narrow width the same controls appear in the existing drawer.
