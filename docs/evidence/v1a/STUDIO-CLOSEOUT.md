## Operator paths

- In **Agents**, open a definition from Library and edit it in Configure or directly on Canvas. Save records a draft; Activate pins the saved revision. The Nodes sidebar follows the graph and reveals an inline binding as a separate node without rewiring it. Drag an attached end to a compatible port to reconnect, or onto empty canvas to disconnect. Double-click the delegation wire to inspect the pinned revision, permitted scope, task and expected result.
- In **Sessions**, use New Session in the right sidebar to pick a previously activated revision. The composer shows the pinned agent and revision. History supports titles, rename, search, grouping by agent or activity date, and optional row descriptions. Inspect Runs opens evidence for that Session, with a return action.
- In **Runs**, the center shows Outcome, recorded Turn and numbered Timeline. The right sidebar contains grouped history and Details. The timeline shows elapsed time and wall-clock time to milliseconds; usage is shown when reported. Open Turn jumps to the corresponding message; governed child and parent Runs link in both directions.
