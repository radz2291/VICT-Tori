1. In **Sessions → New Session → Quellight → r1**, send “Pls remember that I prefer project updates in three short bullets.” Quellight replies in character. On that turn's **Memory proposal** card, use **Correct** to edit the exact text, **Dismiss** to leave it unsaved, or **Confirm and save**. Only the last action creates a receipt and shows **Saved**.
2. From the repaired checkout, restart the same preview using the command below and reload Studio. Open a fresh Quellight r1 Session and send “Give me an Orchid project update.” In the Sessions sidebar, open **Details → Inspect runs**, then read **Saved memory** for the admitted revision.

4. For a context-dependent request, first discuss a planning brief, then ask “Remember how we prepared the planning brief in this Session.” Edit the card before saving, send another turn, and reopen the Session to find the card under the original reply. 5. “Remember to send the planning update” and “Don’t forget to send the planning update” ask **Save as a memory, or set a reminder?** outside Quellight’s reply. No proposal or reminder is created. “Don’t save this as a memory” starts no proposal.
