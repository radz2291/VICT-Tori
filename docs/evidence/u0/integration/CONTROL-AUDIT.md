# Integrated Studio control provenance

The independent install used the 11 artifact hashes in the [G0 manifest](../../g0/vict-artifacts.json). Each public VICT package below is `0.4.0-rc.1` from source `6b420a3e9eada6f694cc2550debda7753316b5b3`. The Studio's own composition owns document intent, layout and synthetic records. Native graph selection and typed ports are provided by VICT.

Studio source contains no directly authored HTML `button`, `input`, `textarea`, `select` or `dialog` elements. Controls in the rendering package retain its standard state and focus behavior. The read-only Agent relationship projection has a text alternative in the same Inspector section. `WorkspaceCanvas.svelte` composes public workspace selection and presentation contracts and leaves the native renderer in charge of graph gestures.

The existing [R2 control audit](../VICT-CONTROL-AUDIT.md) and [TORI-002 audit](../tori-002/final/CONTROL-AUDIT.md) retain their original scope. This checkpoint requests no new exception. Measured browser coverage and remaining gaps are recorded separately from this source inventory.
