# Integrated U0 walkthrough

Use a fresh browser profile or the isolated sample project when you want to repeat a fixture from its starting point. See the [Studio launch instructions](../../../../apps/studio/README.md).

1. Open **File → Open blank project**. On Agents choose **Add agent**, enter instructions in both the node and Inspector, and choose a model, mode, Skill and tool. Check Undo and Redo, then Save. Reopen and fully reload. Library selection should outline the native graph node and drive Inspector. A blank canvas click clears both. Reveal and Delete operate on that selection.
2. Open **File → Open sample project**. On Agents, **Insert** offers the Authoring agent, Quellight workspace and Coding workspace fixtures. For Quellight, check Browser tool availability and Research Specialist delegation in **Show resource relationships**. Hide the projection and check the bindings. Change a field, Undo, then Save and reopen.
3. On Workflows, add a Request, Run agent and Decision. Connect the Request brief to the Run agent input using native ports or **Connect ports**. Try Request brief into Decision proposal and read the type error. The valid edge remains. **Workflow examples** supplies the research and governed workflows with real typed links. Inspect the Decision to preview exclusive, multi-match and no-match routes. Save an incomplete draft and compare it with the readiness diagnostics.
4. Select the Quellight action and choose **Run → Start simulated run**. Inspect the denied result in Runs. Select an ordinary node and create success, wait, failure, cancellation or interruption records. Inspect nested events, their recorded time, inputs, outputs and simulation provenance. Cost stays unknown.
5. In Runs choose **Open linked session**, select an enabled mode and send a synthetic message. Open that message's run, return to the associated definition, then fully reload and reopen the same session and run.
6. On Creative, compare the three directions, select one in Library and branch it. Inspect the reference cycle and choose context explicitly. **Simulate selected direction** runs the selected node, shows unavailable Run To and Run From closure, and supports exact-input reuse and new variations. Edit its notes and see the old version become stale. Follow the artifact to Runs. **Create workflow from selection** appends an editable Request and Run agent with the Creative source ID and context.
7. Open **File → Studio settings** to edit provider, model, Skill, tool, mode and evaluation entries. Save configuration, try a labelled sample check, close, and reopen. Disable a mode and confirm it is unavailable for new messages. Use synthetic configuration details.
8. Repeat Library selection, canvas clear, Reveal, Save and run/session inspection at 390×844. On phone, **Menu** provides the same command families and docks open as dialogs. Test 1531×668 with the docks open and confirm the canvas ends above the page navigator.

U0 provider, tool, model, media, business effect and evaluation execution is simulated. The selected definition and revision are recorded with each simulation. The local adapter declines Run To and Run From when it cannot plan a safe closure and refuses protected actions before dispatch. Creative output is a synthetic VICT vector with a stable artifact ID. Reusing an artifact or continuing its Session preserves the source artifact identity.
