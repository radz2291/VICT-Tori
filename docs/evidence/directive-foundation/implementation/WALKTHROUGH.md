# Quellight Directive walkthrough

Open the [repaired local TORI-009 Studio](http://127.0.0.1:48954/). The isolated workspace starts with Quellight r2. It has governed saved-memory recall and one connected Standing Directive.

1. Open **Sessions**, select a new Quellight Session and send “Going forward, give me Orchid updates in three short bullets. Keep that as my preference.”
2. The ordinary reply comes through the Session. Send a follow-up while interpretation is pending. In **Sessions sidebar → Details → Saved memory**, a pending interpretation has its own **Stop interpretation** action.
3. On the original message’s **Memory proposal** card, choose **Correct**, enter “For future Orchid updates, use two short bullets.” and choose **Review correction**. Check the exact display, then choose **Confirm and save**. The card shows **Saved** once the receipt is established.
4. In **Agents → Configure → Capabilities → Edit Directive**, inspect name, recognition, transcript budget, deadline, output allowance and the effective pin. On the Canvas select Standing Directive and open **Selection** to edit the same fields.
5. While still in the same Session, send “Which standing preference applies to Orchid updates?” and “Give me an Orchid project update.” Quellight should identify the confirmed two-bullet preference and use two bullets. The earlier three-bullet request is still in the conversation.
6. Send “Do you remember what we talked about last week?”, “Do you remember what we discussed last week?” and “Ingat lagi apa kita bincang minggu lepas?” Each is an ordinary question. Quellight should say this walkthrough has no evidence from last week, and no Directive card or clarification should appear.
7. Restart the isolated host on the same data directory and repeat steps 5 and 6 in a fresh Quellight Session. In **Sessions sidebar → Details → Inspect runs**, open the Run’s **Details** and check the admitted memory ID and revision. The previous Run retains the original save receipt.
8. Session **Details → Saved memory** offers **Draft a memory from a turn** for eligible completed turns. Choose the source, enter synthetic wording and choose **Draft memory**. That opens the same review card. **Dismiss** closes it. **Correct memory** and **Forget memory** apply to an already saved record with a separate confirmation.
9. Disconnect Standing Directive, save, activate and start a new Session. Its Details show that the activation is unconnected. A new save request does not open a proposal and the manual draft control is absent. An older pinned Session still resolves its original binding.

For a fresh isolated Windows preview, set `TORI_ZAI_ROUTE=coding`, `TORI_ENABLE_PI_ZAI=1` for the approved local connection, and `TORI_DATA_DIR` to a new directory. Run `node ./node_modules/vite/bin/vite.js --host 127.0.0.1 --port 48954 --strictPort`. In a separate terminal, run `node scripts/seed-directive-preview.mjs http://127.0.0.1:48954` once. Restart on the same directory without reseeding when checking receipts and recall.
