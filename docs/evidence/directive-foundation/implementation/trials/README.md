The same Coding GLM-5.3 Flash model, fixed 173-case baseline, fixed 25-case held-out set, and 16 fresh cases were used for the full trials. Each completed record is retained below. Trial numbers are chronological development evidence. The locked candidate’s qualification, exact interpreter blob and scoring are linked in the [implementation report](../REPORT.md).
