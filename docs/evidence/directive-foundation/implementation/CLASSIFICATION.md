## Public controls in the Studio browser

The installed `@victframework/ui-svelte`, `@victframework/ui-ai-svelte` and `@victframework/ui-flow-svelte` are all 0.4.0-rc.1 from the shared lock. The 1531×850 and 390×844 Windows browser driver exercises the revised surfaces and keeps the established shell, panels and quiet Session feed.

| Surface | Public control and state observed |
| --- | --- |
| Configure and Selection | `Label.Root`, AI `Input` for name and numeric limits, AI `Textarea` for recognition, `Switch.Root` for tuning and VICT `Select` for sensitivity; enabled/disabled, connected/unconnected, invalid draft feedback and pinned effective values. `Button` for Add, Connect, Disconnect, Save and Activate. |
| Canvas and Assembly | Public VICT Flow canvas/ports, existing selection, typed link menu, VICT Tabs and Buttons, shared transaction Undo and Redo via the VICT menu. Compact Directive preview is read-only text. |
| Sessions and Float card | VICT AI prompt/input and VICT Buttons, `StatusBadge`, `Feedback`, labels, textareas and turn Select; pending in Details, Stop, corrected proposal, exact Confirm, Dismiss, Saved, manual draft and quiet recall. Inherited correction/Forget are public VICT Dialog and Buttons verified by the Memory browser suite. |
| Run inspection | Public accordion, status badges, feedback and reconciliation Button. Directive status, exact pin, limit, finish and usage are read-only text with no selectable authority. |

The slice uses composition of the listed public roles. Approval for a replacement primitive was unnecessary.
