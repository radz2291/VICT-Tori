Retained negative probes: stopping the first raw harness before workflow settlement produced LibSQL CLIENT_CLOSED; shutting down multiple raw compositions in the same process after observer cleanup also hit a raw Mastra registry TypeError. These are not used as recovery evidence. The first suspension attempt stopped the driver at onSuspended, before the snapshot was listed; reopen returned “This workflow run was not suspended.” Using generate() and observing the persisted suspended record before process exit established the supported checkpoint. The active-crash failure reproduced on two separate stores with the effect entered twice. No physical machine restart was performed. The implementation will test disk-only cold reopen and make no machine continuation claim.

Decision: retain the existing pinned VICT/Mastra execution paths, separate Studio acknowledgement and observation from the host owner, use VICT replay with authoritative snapshots, and reconcile the original effect identity without replay. No local durable executor, signal service, package upgrade or Studio suspend/resume control. This is dependency evidence, separate from deterministic recovery matrix, browser and live-model acceptance.
