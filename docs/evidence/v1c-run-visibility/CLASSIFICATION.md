# Run Visibility constants and ownership

This inventory covers the new slice only. Existing accepted ranges remain unchanged. [Canvas is the code](../../../AGENTS.md#canvas-is-the-code) distinguishes owner-authored policy, governed mechanics and composition. Local presentation preferences are explicitly outside execution authority in the pinned Run Visibility contract.

| Value / behavior | Classification and owner | Surface / enforcement evidence |
| --- | --- | --- |
| Quiet / Summary / Full trace, Quiet initial display | Local presentation preference; governed vocabulary from contract §1–2 | Sessions/Runs Details; browser/workspace persistence; no activation, retention, Run or dispatch change |
| Collapsed Working / Continued working groups | Local presentation state; governed boundary semantics | Stable workspace/Run/group key; actual `content.completed` and subsequent work; report tests |
| `tori.run-report@1`, `tori.public-event-receipt@1` | Governed schema identifiers | Public package; strict source validation and explicit metadata-only text receipt |
| Allowed strict event kinds and required scope/correlation | Governed installed public VICT contract, unchanged | Installed probes; invalid/private/foreign events refused; original parser passes |
| Deduplicate by stream+sequence, preserve per-stream order, expose gaps/conflicts | Governed evidence mechanics | Deterministic report checks; no timestamp-based invented global ordering |
| Four Run states; authoritative saved outcome wins over transport | Governed recovery semantics inherited from TORI-007 | Report and recovery suites; disconnect never implies interruption |
| Accepted output is text authority; unaccepted delta payload unavailable | Governed existing output/privacy boundary | Retained A4 rejection-canary failure and repaired host/report tests |
| Existing per-agent steps/tool calls/retries, child exact execution pin | Knobs owned by existing Agent Execution authoring; no new ranges/defaults | Existing Configure/Canvas/activation path; reports read actual pins only |
| Combined consumption, null unknown usage, no combined cap | Governed accounting semantics | Unique authorized Run IDs; null means Unavailable; aggregate cap/remaining Not configured |
| Parent questions disabled/unavailable | Composition capability absent at installed public boundary | No new grant, endpoint, policy activation or continuation code; PROBES.md |
| Proposed exchange default 1, range 0–2 | Proposed knob and governed bound in contract, **not ratified or executable** | Unavailable UI only; RV-05–07 remain blocked |
| Synthetic preview agents and their budgets | Explicit fixture/demo authored configuration, not product defaults | Isolated fresh-workspace seed; saved canonical graph and normal activation |
| Preview/test ports, polling timeouts, viewport sizes and test identities | Test/launch mechanics only | Isolated local stores/ports; no agent policy or production authority |

Directive recognition owns its transcript/deadline/output knobs and host reconciliation. Memory Policy/node-family still owns the deferred admission budget, record cap, legacy draft-context budget and proposal lifetime. Deployment retention remains server-owned under its explicit exception. This slice changes none of those policies and does not introduce memory-family surfaces. Public reasoning remains unavailable; no private reasoning is captured or shown.
